Adaptations: coherent source 3.0 only; axes and millimetres converted to Y-up, +Z-anterior metres; per-element uniform 16-bit position quantization with measured Euclidean error <=0.02 mm (float positions otherwise); authored normals normalized and encoded as signed 16-bit with measured angular error <1 degree; lossless Meshopt coding and vertex/triangle reordering. High detail retains every source triangle without geometric decimation. Preview alone uses MeshoptSimplifier with a 0.5 mm estimated appearance error limit; neither generated detail nor subdivision is added. Source meshes and missing structures are not invented.
These art assets have their own license; application code is separate.
